Mouse: click = cursor A (snaps to edges of the clicked row), Shift+click = cursor B, drag = pan, Ctrl/Cmd + wheel = zoom at pointer, Shift + wheel = pan, wheel = scroll rows, drag in the ruler = zoom to range.

Value search: type a value in the signal's current radix, or with a prefix: 0x1F, 0b1010, 'd42, or x / z for any unknown / high-impedance bit.
